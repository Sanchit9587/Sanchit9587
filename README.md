## What I'm into

I like building things end-to-end — from the database up to the model. Lately I've been pulled toward:

- **Agentic systems & RAG** - hierarchical retrieval, knowledge graphs, LLM-as-a-judge evaluation, multi-step routing
- **Applied cryptography** - AEAD ciphers, key derivation, replay-safe protocols
- **Transformers from scratch** - architecture tweaks (RoPE, GQA, QK-Norm), small-model efficiency, CPU-friendly training
- **NLP & entity extraction** - fine-tuning transformer pipelines for domain-specific NER
- **Systems + infra** - containerized deployments, load testing, cloud-native backends

I enjoy going deep on *why* something works rather than just shipping the surface-level version of it.
